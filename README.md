# Raven Finance Bot — AI w edukacji finansowej studentów

Projekt społeczno-edukacyjny dotyczący wykorzystania sztucznej inteligencji w zarządzaniu finansami osobistymi studentów.

## Cel projektu

Celem projektu było sprawdzenie, czy prosty bot AI może wspierać studentów w zapisywaniu dochodów i wydatków, automatycznej kategoryzacji transakcji oraz budowaniu bardziej systematycznych nawyków budżetowych.

## Zakres projektu

W ramach projektu:
- przeprowadzono diagnozę potrzeb studentów,
- przygotowano prototyp Raven Finance Bot,
- przeprowadzono testy z udziałem 30 studentów,
- opracowano wyniki pre-testu i post-testu,
- przeprowadzono warsztaty o możliwościach i ograniczeniach AI,
- przygotowano raport końcowy.

## Technologie

- Telegram Bot API
- n8n
- OpenAI API
- Google Sheets

## Najważniejsze funkcje prototypu

- dodawanie dochodów i wydatków,
- automatyczna kategoryzacja transakcji,
- statystyki finansowe
- rekomendacje oszczędnościowe
- obsługa wiadomości tekstowych,
- obsługa wiadomości głosowych Voice-to-Text,
- usuwanie wybranych zapisów.

## Wyniki techniczne

W okresie testowania odnotowano 643 uruchomienia workflow, 18 nieudanych uruchomień oraz wskaźnik błędów na poziomie 2,80%. Średni czas wykonania jednego zapytania wyniósł 6,75 sekundy.

## Ochrona danych

W repozytorium nie zamieszczono danych osobowych uczestników, szczegółowych zapisów transakcji ani tokenów API. Raport zawiera wyłącznie dane zagregowane i zanonimizowane przykłady działania systemu.
